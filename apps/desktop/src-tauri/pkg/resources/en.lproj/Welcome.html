Welcome to tracr

A local development diary and time ledger for work with several coding agents.

This installs:

  • tracr.app in /Applications, the desktop app.
  • A link /usr/local/bin/tracr to the tracr command line tool that is inside the app.

tracr runs only on your Mac. It reads usage, timing and structure of your Claude Code and Codex sessions after you approve the folders, never prompt or tool text, and uploads nothing.
