# Open questions

Status: **Draft specification v0.2 (2026-09-28)**. Every item is **Unresolved**. IDs are referenced from the other documents.

These questions record uncertainty. Declared invariants are not open: for example, unknown is not work ([AC-12](requirements.md#activity-ac)), bindings never create human time ([TW-09](requirements.md#time-and-worklog-tw)), and operations on human time never reattribute agent records ([AT-10](requirements.md#attribution-at)). The **Status** column separates two cases:

- **Open**: the specification declares nothing on this question yet.
- **Open beyond declared default: …**: the specification already declares a default or a binding rule, named in the cell. A declared default holds until review changes it. Only what lies beyond it is open.
