# Scope

In scope: the T-0004 deliverables and done-when criteria in [architecture.md, Implementation Start](../../architecture.md#implementation-start), plus the `tracr-app` crate required by §1.2 (hosts talk only to `tracr-app`).

Out of scope (later tasks): normalization and `derived.sqlite` (S1.3), human timeline, counting, runtime and OS sensor (S1.4), usage election, pricing and cost (S1.5), the Codex adapter (S1.6), the UI (S1.7), hooks, GitHub and Huly context, and every later-phase feature (Huly writeback, profiles, streaks, contribution graph, governance).

Nothing in T-0004 derives time or money. The ledger stores evidence only; no minute and no cost figure is computed.
