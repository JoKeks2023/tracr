Homebrew

With Homebrew

Installs the app and links the command. Homebrew asks you to trust a third-party tap once.

Homebrew
brew tap JoKeks2023/tracr
brew trust JoKeks2023/tracr
brew install --cask tracr

Command line only: brew install tracr-cli

Verify

Check your download

Compare the checksum with the one above, then ask macOS whether it trusts the file:

Terminal
shasum -a 256 ~/Downloads/tracr-0.10.1-universal.dmg
spctl --assess --type open --context context:primary-signature -v ~/Downloads/tracr-0.10.1-universal.dmg
